# Wails-generated TS bindings (committed placeholders)

This directory holds TypeScript shims for the Wails Go bindings. The real
content is generated by `wails build` (release pipeline) or `wails dev`
(local dev). The committed files in this directory are HAND-WRITTEN
PLACEHOLDERS that satisfy `tsc --noEmit` at PR-CI time.

When you edit Go-side bindings in `internal/panel/bindings.go`, update the
corresponding TS signatures in `go/main/App.ts` to match. The Wails-generated
content during `wails build` will overwrite these placeholders on disk; that
overwrite is expected and harmless because the SHAPES match.

If you see a CI failure of the form `tsc --noEmit` complaining about a
missing import from `./wails/...`, update the matching stub.

Why committed instead of generated in CI?

`wails build` regenerates bindings on production builds, but PR CI runs
`tsc --noEmit` BEFORE `wails build` to fail fast on TS errors. The PR
cross-compile passes `-skipbindings` to keep CI fast and reuse the
committed shapes.
